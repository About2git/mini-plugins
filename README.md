MarketPress Mini Plugins
========================

What is a mini plugin?

- It does only one job.
- It consists of only one file.
- There is no user interface.

These plugins are so tiny, they don’t need separate repositories.

Have fun! Your [MarketPress](http://marketpress.com) Team.

Exception: MS Update Guard
--------------------------

[`ms-update-guard/`](ms-update-guard/) is not a mini plugin. It is a multi-file MainWP Dashboard plugin
with an external test runner and lives here until it gets its own repository. See [`ms-update-guard/README.md`](ms-update-guard/README.md).
